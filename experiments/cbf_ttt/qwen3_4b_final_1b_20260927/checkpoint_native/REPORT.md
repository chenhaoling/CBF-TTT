# 固定12K的checkpoint轨迹与原生TTT诊断

## 结论

1. **读取能力下降在第10000步已经出现。** 原始模型的binding目标/锚点为93.75%/100%，10000步关闭TTT为59.38%/71.88%。本轮只能定位到原始模型至10000步之间，不能确定更细的起点或训练环节。
2. **开启原生TTT不能普遍恢复读取。** 10000步八候选准确率略有提高，40000步和最终checkpoint下降；所有训练模型两种路径均未通过固定binding的16格75%门槛。不能把10000步的候选均值改善称为总体模型恢复。
3. **候选排名掩盖了生成问题。** 40000步和最终原生TTT在全部128个binding查询中，第一步全词表argmax均为token151645 `<|im_end|>`，正确答案首token命中均为0；但只在八个颜色候选内比较仍有非零准确率。这里没有执行完整自由生成，不能推广到其他提示格式或自然任务。
4. **没有发现导出错误或查询污染。** 两个中间checkpoint各413个BF16张量逐值验证；最终零lr原生路径64查询全部候选NLL与plain严格相同。完整矩阵、输入记录、参数/cache不变与结果重算通过审计。
5. 本轮解释了当前实验基座的限制，**没有直接证明或否定附件提出的全局/局部遗忘、多分支标签或端到端联合训练**。暂停该基座的标签扩容，先定位原生多次写入的结束token偏置。

## 与附件要求的关系、下一步与限制

附件的三点分别是：全局与last-1/last-2局部遗忘结合；多处随机遗忘的标签/轨迹；独立策略初始化后端到端NTS联合训练。本轮是这些实验的基座质量诊断，不是三项创新的直接消融，也没有重新构造反事实训练集。

下一步建议（本轮未执行）：

1. 固定相同12K/binding与checkpoint，比较原生累积、只允许一次写入、每块清除旧快权重后写入、禁写等机制对照；同时记录 `<|im_end|>` 概率和正确答案概率，定位多次累积与错误终止之间的关系。必须预先说明清除时点、保留KV以及路径依赖，不能把删掉某次delta当成反事实重放。
2. 对普通读取在10000步前已下降这一问题，核验原训练数据/目标与instruction/readout之间的能力保留，并设计保留原始骨干的稳定writer训练对照。先做少量稳定性验证，不自动重跑1B预训练。
3. 只有读取合格且原生记忆存在稳定收益后，才恢复附件的全局/局部遗忘、多分支标签及联合训练；新来源确认与官方任务评测仍待完成。

局限：已观察dev仅8来源组、64构造场景；固定12K超出原训练6144且从一次写入变为三次；只取3个训练点；完整KV可能掩盖快记忆收益；格式敏感；zero_lr桥接仅最终16场景；报告首token未完整生成；早期改善伴随NLL/首token变差。不能将本轮现象等同Titans/CBF方法优劣或自然任务泛化结论。
