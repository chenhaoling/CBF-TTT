# 配对事实写入器与普通 NLL 对照（2026-09-30）

**两支各 320 步训练完成，均未通过 dev 阶段门，test 未评分。** 配对约束与普通 NLL 的 dev 八选一准确率均为 12.5%，没有证据表明本轮写入器学会区分当前会话事实。远程独立审计已重算并确认此结果。

## 目的与预先固定的设计

上一轮标题任务中，当前论文、错配论文和训练集平均写入均改善 NLL，未证明内容相关记忆。本轮把两个版本的长上下文限制为仅一个事实 token 不同，再比较相同低秩写入器的普通 NLL 与配对约束训练。执行前协议见 [`PAIRED_FACT_WRITER_PILOT.md`](../../../../PAIRED_FACT_WRITER_PILOT.md)。

沿用最终 Qwen3-4B 1B-token checkpoint，冻结骨干及原始 TTT 参数。写入器为 7 层 rank-8 的 `D'=D+B(AD)`，每层范数不超过原候选，共 286,720 个训练参数。它只接收上下文产生的候选矩阵，推理不输入答案。训练时以单 token 答案监督写入器；这是离线训练，不是 test-time 使用真实答案更新。

新论文排除此前全部 232 个唯一源 ID，从相同官方 arXiv feed 固定种子筛选。58 篇尝试得到 48 篇：9 篇长度不足、1 篇下载失败。首次下载因 PDF IncompleteRead 中断；补上有限重试后按相同种子和顺序重跑，保留错误记录。按论文划分为 32 train /8 dev /8 test；每篇追加两个不同颜色的会话事实，共 64/16/16 条。双生上下文恰好只差一个 token，长 4096 token；8 类颜色标签在每个 split 均衡，查询固定，双生版本不跨 split。

这些是人为插入的事实，论文正文作为干扰背景。它们用于测试“改变所读事实是否改变参数记忆”，不代表自然事实问答。相同背景的双生对照比跨论文错配更严格地隔离事实变化。

## 可读性检查与训练

完整 attention KV 保留、关闭快记忆写入时，16 条 dev 的八选一准确率为 **100%**，平均全词表答案 NLL **3.67006**。因此模型能从可见上下文读出事实。正式写入评测清空 KV，仅保留候选产生的快记忆。

两支使用相同 seed=134 初始化、样本顺序、AdamW lr=.001/weight_decay=.01、rank=8、clip=1、g=1、5 epochs×64=320 步。普通支优化 `L_correct`；配对支优化 `L_correct+relu(.1+L_correct−L_twin)`，正确与错配两条路径都对写入器求导。每个双生版本也会作为正样本，避免仅惩罚某一个版本。

每 epoch（含初始）在 dev 评估 g=.5/1，按相对无写入、原始更新、双生错配及 train 平均更新的最差平均 NLL 收益选 checkpoint。阈值和准确率门槛见协议；配对支未通过 dev 时不评分 test。八选一准确率使用候选颜色之间的 argmin NLL，不是自由生成准确率。

## 验证与存档

### 完成结果（dev，共 8 个论文源组、16 条配对样本）

| 方法 | 平均答案 NLL | 八选一准确率 |
|---|---:|---:|
| 完整 KV 保留、无快记忆写入（可读性检查） | 3.67006 | 100% |
| 清空 KV、不写入 | 7.16931 | 12.5% |
| 原始 TTT 候选，dev 选 g=.5 | 7.13607 | 18.75% |
| 普通 NLL 写入器，epoch 1、g=1 | 2.25829 | 12.5% |
| 配对约束写入器，epoch 2、g=1 | 2.22286 | 12.5% |

表中的完整 KV 条件用于检查任务可读性，其他行才是清空 KV 的记忆写入对照。NLL 是全词表答案概率，准确率仅在 8 个预设颜色间比较；二者不能互相替代。配对支相对无写入改善 4.94646 NLL，但对双生错配更新只改善 0.00781、对训练集平均更新改善 0.03004；仅 2/8 源组同时在无写入和双生对照上达到组内改善门槛。普通支相应双生差为 0.01953、5/8 源组改善。两支准确率都是 2/16，均未达到 ≥25% 且超越各对照 ≥12.5 个百分点的要求。

因此，配对约束在本次预算下未带来事实识别收益，按协议保留 16 条 test 未评分。选型只使用 dev，未按结果重设门槛或追加训练。NLL 大幅降低、准确率维持八类均衡任务的随机水平，符合学到“更倾向输出颜色词”这一通用适配解释，但不足以证明正确的事实绑定。不能声称独立 test 失败，因为本轮根本没有评测 test。

远程审计确认：48 个新源与旧 232 个源无交叉、32/8/8 源组划分、双生只差一个 token、标签均衡、96 个候选记录、两支初始化/样本顺序一致、每支每 epoch 完整覆盖 64 个训练样本、各 320 步，以及 dev 选型/门槛和 test 未执行状态一致。

只读 dev 候选诊断也已完成：8 个源组×7 层的相对差异 `||D_a−D_b|| / ((||D_a||+||D_b||)/2)` 中位数为 **0.2378%**，范围 **0.1682%–0.4649%**。矩阵元素发生变化的比例中位数为 41.88%。因此双生候选确实不同，不能把失败归为缓存完全相同；同时整体相对变化较小，是否足以支持可泛化的事实读取仍需新的结构实验，不能单靠范数诊断判断。详情见 [`candidate_signal.json`](candidate_signal.json)。

## 局限

单种子、8 个 dev 源组、人工颜色事实、固定事实位置、单块空旧记忆、低秩左乘和范数约束均限制外推。失败不能证明任何形式的参数记忆或双门控均无效；成功也需要新来源自然事实、自由生成及四条件门控验证。test 是否已评分和最终结论以本报告的完成结果及审计为准。
